# Plantillas de Elementor Pro - Aluminis Albera

24 plantillas `.json`: cabecera, pie y 22 paginas. Todo con contenedores (Flexbox) y widgets de Elementor, sin CSS propio.

## Antes de importar
1. Crea el menu de WordPress **Menu principal** (Inici, Productes, Projectes, Sobre nosaltres, Contacte).
2. Importa `header.json` y `footer.json` en Elementor Pro > Theme Builder (condicion: todo el sitio).
3. Importa las paginas en Plantillas > Importar y crea cada pagina con la **URL (slug)** de la tabla.
